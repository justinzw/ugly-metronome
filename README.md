# Ugly Metronome

The ugliest metronome ever created. It works, but you'll hate looking at it.

## Features

- Fully functional metronome (40-208 BPM)
- Realistic swinging pendulum animation
- Audio click on each beat
- Ugly color scheme that hurts your eyes
- Papyrus font because why not

## Usage

Open `index.html` in any browser and click START to begin.

## Tech

- Pure HTML/CSS/JS
- Web Audio API for sound
- No dependencies
